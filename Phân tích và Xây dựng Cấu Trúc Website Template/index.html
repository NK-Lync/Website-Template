HTML Introduction

HTML stands for HyperText Markup Language. It is used to describe the structure of a web page.

A Simple HTML Document

The following example shows the basic structure of an HTML document.

Example

<!DOCTYPE html>
<html lang="en">
<head>
    <title>Page Title</title>
</head>
<body>

    <h1>My First Heading</h1>
    <p>My first paragraph.</p>

</body>
</html>

HTML Elements

An HTML element is defined by a start tag, some content, and an end tag. Elements form the building blocks of web pages.

Note: Some HTML elements have no content and do not need a closing tag.

HTML Attributes

HTML attributes provide additional information about HTML elements.

Example

<a href="https://www.w3schools.com">
    Visit W3Schools
</a>
